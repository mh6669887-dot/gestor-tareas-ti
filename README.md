# Gestor Web de Tareas para Pequeños Proyectos TI

Aplicación web para registrar y hacer seguimiento a tareas de un equipo de trabajo.  
Desarrollada con HTML, CSS y JavaScript puro.

## Funcionalidades

- Inicio de sesión con usuarios preconfigurados
- Crear, editar y eliminar tareas
- Asignar responsable, fecha límite, estado y prioridad
- Filtrar tareas por estado (Pendiente, En proceso, Terminada)
- Resumen de avance con barra de progreso
- Almacenamiento en el navegador (localStorage)
- Diseño responsive — funciona en computador y celular
